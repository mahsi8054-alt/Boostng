# BoostNG

BoostNG is a modern SaaS platform that enables creators, businesses, and marketers to purchase social media growth services through a secure wallet system powered by GoMine.

## Features

- Clerk Authentication
- Supabase Database
- Wallet System
- Paystack
- Flutterwave
- GoMine API
- Customer Dashboard
- Admin Dashboard
- Referral System
- Coupon Engine
- Light/Dark Theme
